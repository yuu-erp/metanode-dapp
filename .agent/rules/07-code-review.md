# Code Review Checklist

## Rules (EN)

- No console.log, debugger, or commented-out code.
- No magic numbers without explanation.
- No TODO without ticket reference.
- Critical logic MUST have tests.

## Giải thích (VI)

- Review để nâng chất lượng, không phải để bắt lỗi cá nhân
- Checklist giúp review nhất quán giữa các reviewer
