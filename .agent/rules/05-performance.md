# Frontend Performance Rules

## Rules (EN)

- Memoization MUST be justified with measurable benefit.
- Large features SHOULD be code-split and lazy-loaded.
- Avoid unnecessary re-renders and expensive computations in render phase.

## Giải thích (VI)

- Không tối ưu mù quáng
- Đo trước – tối ưu sau
